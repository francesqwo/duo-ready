How this works

  1. Every day a GitHub Action scans the US App Store: top-free 100, top-paid 100, and Apple's own “Great Apps and Games on iPhone Duo” collections.
  2. For each app it reads the public App Store catalog record and looks for the iPhone Duo screenshot slot. Duo screenshots are the only assets at 1398×2034 / 2034×1398 (outer display) and 2007×2853 / 2853×2007 (inner display).
  3. Apple shows the Made for iPhone Duo badge once an app submits those screenshots, so the slot is the machine-readable counterpart of the badge.

Caveats: “Not yet” means no Duo screenshots uploaded — an app can be recompiled for iOS 27.1 and still show nothing here. From April 2027 Apple requires Duo screenshots for new submissions, so the “not yet” column will drain. Data comes from an undocumented App Store endpoint and can break without notice.
